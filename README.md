# FoodStorage — сервис контроля запасов продуктов

## Назначение

Приложение помогает учитывать продукты дома, определять необходимость покупки
и следить за сроками годности. На этапе ПР1 реализован консольный сценарий
проверки одного запаса продукта.

## Целевая аудитория

Люди и семьи, которым нужно планировать покупки и сокращать количество
продуктов, выбрасываемых из-за истечения срока годности.

## Предметная область

Домашние продуктовые запасы. Один продукт может иметь несколько запасов
(партий) с разным количеством и сроком годности. Количество учитывается
в единице измерения продукта. Минимальный желаемый запас задаёт пользователь.

## Основные сущности

- **Продукт**: название и единица измерения.
- **Запас**: партия конкретного продукта, её количество и срок годности.
- **Количество**: числовое свойство запаса, например 2 литра.
- **Срок годности**: дата, до которой учитывается годность конкретной партии.

В ПР1 данные представлены отдельными переменными. Коллекции и классы
будут добавлены в следующих работах.

## Основные функции

В ПР1 реализованы три функции приложения:

1. Проверка достаточности запаса (`get_stock_status`): сравнение текущего
   количества с минимальным желаемым.
2. Расчёт количества для покупки (`calculate_purchase_quantity`): разница
   между минимальным и текущим количеством; при достаточном запасе — ноль.
3. Проверка срока годности (`get_expiry_status`): просрочен, истекает сегодня,
   истекает в ближайшие три дня или ещё не истекает.

Завершённый сценарий выводит сведения о продукте, состояние срока годности,
достаточность пригодного запаса и необходимое количество для покупки.
Просроченное количество не учитывается при расчёте покупки. В учебной модели
запас с сегодняшней датой окончания срока ещё учитывается.

## Рабочее окружение и запуск

Проверено на Python 3.13.7. Сторонние библиотеки не нужны.

Из корня проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python main.py
```

Если окружение уже создано, первый шаг повторять не нужно. Без активации:

```bash
.venv/bin/python main.py
```

В VS Code откройте папку проекта, выполните `Python: Select Interpreter`
и выберите `.venv/bin/python`. Для запуска и отладки нужны расширения
Microsoft Python и Python Debugger. Конфигурация отладки включена в проект.

В `main()` заданы демонстрационные данные: молоко, 2 литра, желаемый запас
5 литров и срок годности через два дня от даты запуска. Измените переменные
в начале `main()`, чтобы проверить свой продукт. Количества должны быть
неотрицательными и выражаться в одной единице измерения.

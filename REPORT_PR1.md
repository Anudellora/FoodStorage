## 3. Индивидуальный проект

**Название:** FoodStorage — сервис контроля запасов продуктов.

**Предметная область:** учёт домашних продуктов, планирование пополнения
запасов и контроль сроков годности. Пользователи — люди и семьи,
которые хотят рационально планировать покупки.

Основные сущности — продукт и запас продукта. Количество и срок годности
описывают запас. На текущем этапе данные представлены отдельными переменными.

Реализованы три функции: проверка достаточности запаса, расчёт количества
для покупки и проверка срока годности. Программа проверяет одну партию
продукта и выводит результат. Просроченная партия не включается
в пригодный запас при расчёте покупки.

**Репозиторий:** https://github.com/Anudellora/FoodStorage  
**Согласование темы с преподавателем:** требуется подтверждение студента.

## 4. Результаты

Используется установленный Python 3.13.7. Создано виртуальное окружение
`.venv`, подготовлены настройки запуска и отладки для VS Code.
В локальном Git-репозитории настроен удалённый адрес `origin`.
Созданы README.md, .gitignore и main.py. Использованы простые типы данных,
преобразование строки в число, арифметика, сравнения, ветвления, функции
и импорт из стандартного модуля datetime.

Программа успешно запущена: при наличии 2 литров молока и желаемом запасе
5 литров рассчитана покупка 3 литров. Проверены варианты достаточного
и отсутствующего запаса, истёкшего и приближающегося срока годности.

С помощью pdb выполнена пошаговая отладка с точкой останова и просмотром
переменных. Во временной копии выявлена и исправлена ошибка порядка
операндов вычитания: результат изменился с −3 на 3. Демонстрация отладки
в интерфейсе VS Code предстоит; порядок действий приведён в DEBUGGING.md.

Результат ПР1 сохраняется в локальном Git-репозитории.
Отправка файлов в GitHub на момент подготовки отчёта не выполнена.

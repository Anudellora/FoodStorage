# Отладка ПР1

## Демонстрация в VS Code

1. Откройте папку FoodStorage в VS Code и выберите интерпретатор
   `.venv/bin/python` через `Python: Select Interpreter`.
2. Откройте `main.py` и поставьте точку останова на строке 20:
   `return minimum_quantity - quantity`.
3. На панели «Запуск и отладка» выберите «FoodStorage: отладка ПР1»
   и нажмите F5 (на некоторых клавиатурах — Fn+F5).
4. В панели переменных проверьте `quantity = 2.0` и
   `minimum_quantity = 5.0`. В Debug Console можно вычислить
   `minimum_quantity - quantity`: результат `3.0`.
5. Выполните шаг F10, проследите возврат из функции и продолжите до строки 53.
   Значение `purchase_quantity` должно быть `3.0`.
6. Нажмите F5, чтобы завершить выполнение и увидеть вывод программы.

## Упражнение с ошибкой

Временно замените на строке 20 выражение `minimum_quantity - quantity`
на `quantity - minimum_quantity`. Повторите отладку. При исходных значениях
2 и 5 получится `-3.0`: порядок операндов вычитания перепутан.
Верните правильное выражение, повторите запуск и проверьте результат `3.0`.
Сохранённая версия `main.py` содержит правильное выражение.

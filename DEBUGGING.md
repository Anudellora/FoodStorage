# Отладка FoodStorage

## ПР3: демонстрация в VS Code

1. Откройте папку проекта, выберите `.venv/bin/python` через
   `Python: Select Interpreter` и запустите «FoodStorage: отладка ПР3» (F5).
2. Через пункт 2 добавьте продукт: молоко, единица `л`, минимум `5`.
   Если такой продукт уже есть, используйте его ID и учитывайте его партии.
3. Через пункт 3 добавьте партию на 2 л со сроком годности через два дня.
4. В `stocks.py`, в методе `Stock.consume`, поставьте точку останова
   на `validate_quantity(quantity, positive=True)`.
5. Выберите пункт 5, укажите ID созданной партии и количество списания `0.5`.
6. При остановке проверьте `self`, `self.product`, `self.quantity`,
   `self.expiry_date` и аргумент `quantity`. `self` — объект партии;
   `self.product` — объект продукта; количество до списания — 2.
7. Выполняйте F10 до завершения присваивания `self._quantity`.
   Остаток должен стать 1.5. Нажмите F5, чтобы сохранить операцию.
8. Для проверки расчёта покупки поставьте точку останова в методе
   `Product.calculate_purchase_quantity` на `validate_quantity(quantity)`
   и выберите 9. При единственной пригодной партии остатком 1.5 л
   и минимуме 5 л результат составляет 3.5 л.
9. Попробуйте списать больше остатка. Программа сообщает об ошибке,
   количество не меняется. При выходе и новом запуске сохранённый остаток
   восстанавливается из JSON как объект Stock со ссылкой на Product.

## Проверка объектной модели в Python

```python
from pathlib import Path
from storage import load_data

data = load_data(Path("data/example.json"))
product = data["products"][0]
stock = data["stocks"][0]
print(type(product).__name__)  # Product
print(type(stock).__name__)  # Stock
print(stock.product is product)  # True
print(stock)  # Вызывается Stock.__str__
```

Количество доступно через свойство `stock.quantity`; обычное присваивание
`stock.quantity = -1` вызывает AttributeError. Для изменения используйте
`stock.consume(...)` или функцию `consume_stock`, которая также удалит
полностью израсходованную партию из коллекции. Подчёркивание в `_quantity`
обозначает непубличное состояние, а не абсолютный запрет доступа в Python.

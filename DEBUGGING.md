# Отладка FoodStorage

## ПР2: демонстрация в VS Code

1. Откройте папку проекта и выберите `.venv/bin/python` через
   `Python: Select Interpreter`.
2. Запустите конфигурацию «FoodStorage: отладка ПР2» клавишей F5.
3. Через пункт 2 добавьте молоко: единица `л`, минимум `5`.
4. Через пункт 3 добавьте партию: количество `2`, срок годности через два дня.
5. В `stocks.py` внутри `calculate_purchase_quantity` поставьте точку останова
   на строку `return float(Decimal(str(minimum_quantity)) - Decimal(str(quantity)))`.
6. В меню выберите 9 — список покупок. При остановке проверьте
   `quantity = 2.0`, `minimum_quantity = 5.0`.
7. Выполните шаг F10, затем F5. В списке покупок должно быть 3 л молока.
8. Для демонстрации коллекций поставьте точку останова на `for product in products`
   внутри `shopping_list`, просмотрите `products`, `stocks` и текущий `product`.
9. Для демонстрации исключений попробуйте списать 3 л из партии на 2 л.
   Программа должна сообщить об ошибке, сохранив прежнее количество.

## Выполненные проверки ПР2

На подготовленном JSON-примере выполнена пошаговая отладка через `pdb`.
Для воспроизводимости расчёт проверялся на фиксированную дату 24.09.2026:
после исключения просроченной партии `quantity = 2.0`, минимум равен 5,
возвращаемое значение равно 3.0.

Автоматизированные проверки охватывают ввод ошибочных чисел и дат,
недопустимые операции с партиями, сохранение и повторный запуск приложения,
повреждённые данные и отказ записи. Тесты запускаются командой `pytest -v`.
Отладка в графическом интерфейсе VS Code остаётся частью демонстрации студентом.
